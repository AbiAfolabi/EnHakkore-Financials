# Financial Advisor Website

Editable source-code project for the financial advisor consultation website.

## Project structure

- `index.html` — page content and structure
- `css/style.css` — all visual styling
- `js/main.js` — client-side JavaScript
- `images/` — place your logo, headshot, and other assets here

## Google Calendar booking

The booking section is connected to the Google Calendar appointment schedule supplied for this site.

Google Calendar appointment schedules provide a booking page, availability controls, and automatic calendar conflict checking.

If you change your Google appointment schedule, update the booking `iframe` URL in `index.html`.

## Local editing

No build step is required.

Open `index.html` directly in a browser for basic editing/testing, or use VS Code and its Live Server extension for a better development workflow.

## Deploying

Recommended workflow:

1. Create a GitHub repository.
2. Upload this project.
3. Connect the repository to Netlify.
4. Netlify automatically deploys changes pushed to the production branch.

## Before public launch

Replace all placeholder business information, credentials, claims, contact information, and disclosure language with your actual, compliance-approved information.

In particular, review:
- Advisor name and firm name
- Credentials/designations
- Experience/client statistics
- Fiduciary language
- Investment-advisory registration language
- Privacy policy
- Terms of use
- Required regulatory disclosures
